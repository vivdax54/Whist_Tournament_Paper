# Whist_Tournament_Paper

**Author:** Vivaan Daxini
**Status:** Unpublished research manuscript
**Date:** October 2026

## Abstract

Whether a Z-cyclic whist tournament on $q^2$ players exists for every prime $q \equiv 3 \pmod 4$ is a long-standing open question; previous literature has only verified the existence of such tournaments for all $q < 5000$. This approach reframes Leonard's patterned-starter construction as a matching problem on a hypergraph. We obtain $N(q) = q^3+q^2+1$ valid quadruples $[a,b;u,v]$ and show that every vertex of the hypergraph $H(q)$ has degree $O(q^2)$ while every pair of distinct vertices has codegree $O(q)$. We use the Frankl--R\"odl--Pippenger theorem to prove the existence of, for large $q$, a collection of $\tfrac{q+1}{2}-o(q)$ pairwise disjoint tables $(A,B,-A,-B)$.
